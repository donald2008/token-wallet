## 战略赌注（一段话）

大屏的「不专业」不在数据（D-055 数据面已通）不在 token 体系（R1-4 已生效），在**执行层从未被专业参考锚定过**。本周期赌注：用两个锁定锚点（dk-a1 数字纪律 × dk-a3 面板语法）+ monitor 七大来源清单，把 AgentDashboardC 的执行层整体重做一遍——**骨架保留（总→分阅读流无硬伤，R3-3），皮肤与品质基线推倒重锚**。演示场景 3 秒专业感由「数字排版纪律 + 面板语法 + 语义色克制」三者合成，不靠加模块、不靠加图表。

## 不做清单（explicit drops，含理由）

| 不做 | 理由 |
|---|---|
| 下钻交互/多维联动筛选 | 北极星=演示专业感；交互是分析场景需求，演示 3 秒内用不到；不做假想需求 |
| 同环比/历史对比大改 | 需新增 daemon 查询面；本轮仅 S8 零成本均值线，对比维记 backlog |
| 自定义布局/模块开关 | 同上，过度设计 |
| 新数据维度（延迟/错误率等） | daemon 现有能力外，违「数据现状验收基线」边界 |
| 大屏窗口尺寸大改 | 900×640 是 D-024 家族观感定案，版式在该画布内解 |
| 面板增减（仍为 hero+2×2） | 骨架立场；面板内重组自由 |
