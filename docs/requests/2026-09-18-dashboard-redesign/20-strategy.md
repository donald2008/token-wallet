## mock 计划（阶段 4，2-3 个 IA 立场，非纯皮肤差异）

每个 mock = 独立信息架构立场 + 同一 S1-S14 执行基线 + 真实字段形状数据（mcpQueryTypes）+ **必含无 daemon 降级态**：

1. **Ops Wall**（dk-a3 立场）：监控墙 panel grid——一切皆面板，密度最高，agent 为一组行
2. **Terminal Ink**（dk-a1 立场）：数据终端——大数字带 + 等宽密度，分屏不对称
3. **Console**（ed-d2 立场）：工作台主从——左 agent 列表右详情（master-detail）

表达形式 = HTML 静态页；design-qa 门禁对 S1-S14 逐条核验；GATE 2 选型后胜出 IA 进入规格细化与工程交接。
