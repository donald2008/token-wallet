## 北极星

**GATE 3 真机验收零返工一次通过**——专业度判定锚定锁定参考（musepool fetch 产物 + token-monitor 七大来源清单）逐项比对，非主观印象。

## 领先指标与层级

```
北极星：GATE 3 一次通过（零返工轮）
  ← 领先指标 L1：design-qa 三层门禁全绿（程序化 lint / 参考比对 vision / 反默认扫描）
  ← 领先指标 L2：GATE 2 设计门禁一次过（design-gate.json approved 由老大亲手翻）
  ← 输入层：8px 网格零违例 / 主色来自锁定参考 / 图表形态全部有先例锚点 / tabular-nums 右对齐成列
```

优先级流向：一切决策向「演示场景 3 秒专业感」收敛；**因此降级的**——下钻交互、多维联动筛选、自定义布局、新数据维度接入（daemon 现有能力之外）全部不做（不为假想需求过度设计）；时间范围筛选保留现状四档。

## 正确性契约（本周期）

- 允许的断言：带 FOUND/INFERRED 标签的设计事实、带参数的参考锚点、可证伪的验收场景
- 数字类断言（对比度、字号、间距）一律落 tokens/design-lint 可程序化验证的形态，不写「感觉协调」类不可验断言
- 错误代价：规格层写错形态=工程返工一轮，宁缺勿错；无证据的断言标 NEEDS-CONFIRMATION 不冒充结论
